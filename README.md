# hw2-recipes
Система для управления рецептами и создания списка покупок.
## Автор
Гаглоева Елизавета Юрьевна, ББИ2504
## Установка
1. Клонируйте репозиторий:
```bash
git clone https://github.com/elizavettaa69/hw2-recipes.git
cd hw2-recipes
```
2. Установите зависимости: 
```bash
pip install -r requirements.txt
```
## Использование 
Запуск тестов:
```bash
pytest test_recipes.py -v
```
